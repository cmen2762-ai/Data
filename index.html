URL Web App telah terpasang otomatis. Sheet Database_Rapor_SD beserta seluruh kolom header akan dibuat otomatis saat data dikirim.

Langkah Singkat Pemasangan:

  1. Buka Google Spreadsheet baru → klik menu Ekstensi > Apps Script.
  2. Tempel kode dari file Code.gs yang telah disediakan, lalu simpan.
  3. Klik Terapkan (Deploy) > Deployment baru > Aplikasi web.
  4. Atur Yang memiliki akses menjadi Siapa saja (Anyone), lalu klik Terapkan.
  5. Salin URL Aplikasi web dan tempel pada kolom di atas.
